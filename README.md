# Luxe Stay - Luxury Hotel Management System

A modern, responsive, and feature-rich hotel management application built with React and Tailwind CSS. This project demonstrates a comprehensive frontend solution for a luxury hotel, including room booking, restaurant ordering, and an admin dashboard.

## Features

*   **Luxury User Interface**: A premium, visually stunning design with smooth animations and high-quality imagery.
*   **Room Booking System**: Browse rooms, view details, and book stays with a seamless modal interface.
*   **Restaurant & Dining**: Explore the menu, add items to a cart, and place room service orders.
*   **Admin Dashboard**: A secure, protected area for administrators to manage bookings and orders.
    *   **Authentication**: Secure login (Demo: `admin@luxestay.com` / `admin123`).
    *   **Analytics**: Visual summary of bookings, orders, and revenue.
    *   **Responsive Design**: Optimized for both desktop and mobile management.
*   **Toast Notifications**: Professional, non-intrusive alerts for user interactions.
*   **Responsive Design**: Fully functional across all device sizes, from mobile phones to large desktops.

## Tech Stack

*   **Frontend**: React 19, React Router v7
*   **Styling**: Tailwind CSS v4, Lucide React Icons
*   **Build Tool**: Vite
*   **State Management**: React Context API + LocalStorage

## Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/yourusername/hotel_management.git
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```

## Deployment

This project is configured for deployment on GitHub Pages.

```bash
npm run deploy
```
